# ACO 499 Software Development Internship
## Customizing Educational Database Applications

**Arizona State University · Applied Computing · 2022–2023**  
**Faculty mentor:** Dr. Suzanne Dietrich  
**Student:** Kathleen Kagan

## Project overview

Across two semesters of ACO 499 individualized instruction, I worked with Dr. Suzanne Dietrich on the customization and continued development of educational database applications, including **DesignDB** and **IntroDB**, within the broader *Databases for Many Majors* project.

The applications introduce database concepts to students with varied technical backgrounds. The instructional material covers entity-relationship diagrams, entities and attributes, relationships, relational mapping, and introductory SQL concepts.

My internship work involved learning and navigating an existing Java/JavaFX application, customizing instructional content and interfaces, working with XML-backed material, and investigating behavior across application views and methods.

This was collaborative work on an established educational software project—not a claim that I independently authored the entire application.

## Two-semester progression

### Semester 1 — DesignDB customization (2022)

The first semester focused on understanding the existing *Databases for Many Majors* application and contributing to the customization of DesignDB.

My December 2022 reflection describes the initial challenge as strengthening my Java foundation while learning how the application combined JavaFX and XML. I worked with the existing codebase and instructional content, developing familiarity with its structure and the way the program presented database concepts.

### Semester 2 — IntroDB and continued DesignDB work (Spring 2023)

The second semester extended the work to IntroDB while continuing the effort to finish and refine DesignDB.

In my April 2023 reflection, I describe working across methods, investigating how changes affected other parts of the program, and testing customization behavior in the interface and XML data. I also document known unfinished areas and issues that required further work by the faculty developer or a future contributor.

The project materials show work with:

- **Java** — application logic, methods, classes, and controllers
- **JavaFX** — desktop application interface and interactive views
- **FXML** — declarative layouts for JavaFX screens
- **XML** — structured instructional content and customization data

The source archive includes application areas and screens associated with entities, relationships, ER diagrams, mapping, checkpoints, tables, questions, and instructional navigation.

## Engineering work and learning

The internship gave me experience with several practical software-development activities:

- Reading and understanding an existing, multi-class Java application
- Tracing behavior across methods and controllers rather than treating code blocks in isolation
- Relating JavaFX interface behavior to FXML layouts and XML-backed content
- Making and evaluating interface and instructional-content customizations
- Testing changes in the customization view, main application, and saved XML
- Investigating issues where interface changes did not persist or where saving/loading behavior failed
- Comparing patterns across related applications and looking for consistency and maintainability
- Learning to research unfamiliar code independently and ask focused questions when blocked

My second-semester paper records concrete areas that remained unresolved at the end of the term, including customization controls that did not update consistently across the interface and XML, save-to-file behavior, and layout issues in some views. I include these as documented project status, not as completed fixes.

## Professional development

A major part of the experience was learning how to contribute to an existing software project with guidance from its developer. My reflections discuss becoming more independent in researching unfamiliar methods, testing assumptions, managing time, accepting iteration, and asking for help after first investigating a problem.

The experience strengthened my confidence working with Java and helped me understand that maintaining and extending an existing application requires careful attention to consistency, dependencies, and the effects of changes across the system.
