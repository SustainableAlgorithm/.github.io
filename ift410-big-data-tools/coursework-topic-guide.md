# IFT 410 — Big Data Tools and Practices: Coursework Topic Guide

**Arizona State University · Spring 2023**

This guide organizes the main subject areas represented in the IFT 410 archive. It is a topic index, not a replacement for the original assignment instructions or lab submissions.

## Module 1 — Python foundations and data structures
- Lists and one-/two-dimensional arrays
- Dictionaries and key-value data
- Reading and parsing files
- Pandas DataFrames: columns, indexes, data types, sorting, selection, filtering, and descriptive statistics
- Dataset exploration and frequency counts

## Module 2 — Understanding and preparing data
- Data attributes and measurement scales
- Data quality and preliminary processing
- Similarity and correlation
- Pearson and Spearman correlation
- Dataset preparation and interpretation

## Module 3 — Data mining tasks and classification
- Data mining tasks and classification concepts
- Decision-tree classifiers, k-nearest neighbors, and support vector machines
- Gini impurity and classification reasoning

## Module 4 — Model selection and evaluation
- Training and test data
- Evaluation measures and prediction error
- Cross-validation
- Spark ML pipelines and parameter grids
- Decision-tree model evaluation

## Module 5 — Regression
- Regression problem formulation
- Linear and nonlinear regression concepts
- Model coefficients and prediction error
- RMSE interpretation and Spark regression exercises

## Module 6 — Clustering
- Center-based, contiguity-based, and density-based clustering
- K-means and related concepts
- Cluster quality and silhouette scores
- Comparing candidate values of K

## Module 7 — Anomaly detection
- Definition and motivation for anomaly detection
- Model-based and semi-supervised approaches
- Exploring numerical attributes for unusual observations

## Module 8 — Big-data storage and Spark SQL
- Distributed storage concepts
- Row-oriented and column-oriented storage
- Spark SQL and data access patterns

## Module 9 — ETL and data processing
- Extraction, transformation, and loading
- Data transformation for machine learning
- File formats and data-processing workflows

## Module 10 — Big-data platforms
- Hadoop architecture: HDFS, MapReduce, and YARN
- Apache Spark
- Scala introduction

## Module 11 — Big-data lifecycle
- Big-data cycle and workflow considerations

## Module 12 — Recommendation systems
- Collaborative filtering
- MovieLens ratings data
- Explicit feedback and rating matrices
- RMSE as a recommendation-model evaluation measure
- Spark-based collaborative-filtering lab

## Module 13 — IT roles in big data
- IT roles and responsibilities in big-data environments

## Notes on the submitted work
The archive includes conceptual assignments, written analyses, Python scripts, Spark exercises, and lab results. Not every module has a standalone program suitable for public release. This public entry highlights representative code and documents wider subject coverage without publishing the entire course archive.
